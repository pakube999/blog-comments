# blog-comments

GitHub Discussions repository for [codexasystems.net](https://codexasystems.net).

Comments on blog posts are powered by [Giscus](https://giscus.app) — an open source comments system backed by GitHub Discussions.

## How it works

- Each blog post maps to a Discussion thread in this repo
- Visitors comment via GitHub login on the blog post itself
- Discussions are created automatically on first comment
- Moderation happens here in GitHub Discussions
